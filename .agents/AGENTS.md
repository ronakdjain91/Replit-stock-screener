# Antigravity Workspace Rules

This file defines the project-specific agent rules and behavioral constraints for the **Stock Screener** project.

## Tech Stack
- Frontend: Vanilla JavaScript, HTML5, Vanilla CSS
- Backend: Python (Flask)
- APIs: Yahoo Finance (yfinance) for both technical and fundamental data

## Guidelines
- No React or complex frontend frameworks. Keep everything in Vanilla JS.
- No TailwindCSS unless requested. Keep styling in Vanilla CSS.
- Run the flask app via `.venv\Scripts\python app.py` for local testing.
- Stock data consists of Nifty 50, Nifty 100, and Custom Lists.
- We have merged both Technical and Fundamental downloads into a single "Analysis Report".
